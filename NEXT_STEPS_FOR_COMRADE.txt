NEXT STEPS TO CATCH UP WITH THE PROJECT
=======================================

Context:
- The Docker stack (PostgreSQL + Zabbix + Grafana) is already working on Louay's machine.
- Zabbix and Grafana are reachable, and Grafana is connected to the PostgreSQL database.
- You need to reproduce the same environment on your PC and arrive at the same point in the plan.

------------------------------------------------------------
1) Prerequisites on your PC
------------------------------------------------------------
- Install Docker Desktop (with WSL2 backend if you are on Windows 10/11).
- Install Git.
- Make sure you have:
  - At least 8 GB RAM
  - Around 25 GB of free disk space

------------------------------------------------------------
2) Clone the repository
------------------------------------------------------------
Open a terminal and run:

git clone https://github.com/yakshaxo/PFE_AI_Audit_AmenBank.git
cd PFE_AI_Audit_AmenBank

DO NOT edit or commit anything to main yet; just follow the steps below to set up your environment.

------------------------------------------------------------
3) Create and configure your .env file
------------------------------------------------------------
1. Create your personal .env from the template:

cp .env.example .env

2. Open .env and at least set:
- POSTGRES_PASSWORD=admin               (or another secure value you choose)
- GRAFANA_ADMIN_PASSWORD=admin         (or another password you choose)

Notes:
- .env must NEVER be committed to Git (it contains passwords and secrets).
- The values you set here must match what you will use later in Grafana.

------------------------------------------------------------
4) Start the Docker stack
------------------------------------------------------------
From the project root (where docker-compose.yml is located), run:

docker compose up -d

Then verify everything is running:

docker compose ps

You should see at least:
- pfe-postgres     (Up)
- pfe-zabbix-server (Up)
- pfe-zabbix-web    (Up)
- pfe-grafana       (Up)

If one of them is not Up, check its logs:

docker compose logs -f <service-name>

(Example: docker compose logs -f postgres)

------------------------------------------------------------
5) Access Zabbix and Grafana
------------------------------------------------------------
Zabbix:
- URL:  http://localhost:8080
- Login:  Admin
- Password:  zabbix

Once logged in, you can optionally change the Admin password:
- Administration → Users → Admin → Change password.

Grafana:
- URL:  http://localhost:3000
- Login:  admin
- Password:  the value of GRAFANA_ADMIN_PASSWORD in your .env

------------------------------------------------------------
6) Configure PostgreSQL data source in Grafana
------------------------------------------------------------
Goal: connect Grafana to the same PostgreSQL database used by Zabbix.

Steps:
1. In Grafana left menu, go to:
   Configuration → Data sources → "Add data source".
2. Choose "PostgreSQL".
3. Fill the form as follows:
   - Name: grafana-postgresql-data source  (or any name you like)
   - Host: postgres:5432
   - Database: zabbix
   - User: zabbix
   - Password: (use POSTGRES_PASSWORD from your .env, e.g. admin)
   - SSL mode: disable
4. Click "Save & test".
   - It must be green (connection successful). If not, check Host/Database/User/Password.

------------------------------------------------------------
7) Create your first simple panel in Grafana
------------------------------------------------------------
1. In Grafana, go to:
   Dashboards → New → New dashboard.
2. Click "Add visualization".
3. Choose the PostgreSQL data source you just created.
4. In the query editor (SQL mode), use this test query:

   SELECT now() AS "Current time";

5. Click "Run query".
6. Change the visualization type to "Table" (right side panel, under Visualization).
7. Click "Apply" (top right).
8. Save the dashboard (disk icon), give it a name like "Test PostgreSQL connection".

If you see a table with one row containing the current time, then:
- Docker is working.
- PostgreSQL connection from Grafana is OK.

At this point you are at the same level as Louay regarding infrastructure and Grafana-PostgreSQL integration.

------------------------------------------------------------
8) (Optional) Add your own PC as a monitored host (Windows)
------------------------------------------------------------
Later, we will need both Windows and Linux hosts. For now, here is how to add your own PC as a Windows host monitored by Zabbix.

1. Download and install Zabbix Agent for Windows:
   - Go to the official Zabbix website, download the Windows agent installer (version compatible with the Zabbix server, e.g. 6.4).
2. During installation, or in the agent config:
   - Set the "Server" and "ServerActive" fields to the IP address of the machine running the Zabbix server.
     - If Docker and Zabbix are on the same PC as you, this is usually 127.0.0.1 or your local IP.
   - Set the "Hostname" to something unique, e.g. HAKIM-PC.
3. In the Zabbix web UI:
   - Go to Configuration → Hosts → Create host.
   - Host name: the same name you used in the agent config (e.g. HAKIM-PC).
   - Groups: choose an existing group like "Windows servers" or create one.
   - Interfaces: add an "Agent" interface with the IP address of your PC (127.0.0.1 if same machine).
   - Templates: link a template such as "Template OS Windows by Zabbix agent".
4. Save the host and wait a few minutes.
5. Check Monitoring → Latest data to see if metrics from your host are arriving.
